## 주요 기능

- **메인 지도**: 카카오맵 위에 착한가격업소 표시, 업종·가격 필터, 지역 검색, 마커 묶음, 북마크
- **회원**: 회원가입, 로그인, 아이디·비밀번호 찾기(이메일 인증), 마이페이지
- **챌린지**: 절약 챌린지 개설·참여, 댓글로 인증
- **커뮤니티**: 자유게시판, Q&A 게시판, 베스트 게시글(추천 수 TOP 10)
- **파티**: 함께 갈 사람 모집, 모임 채팅, 모임비 정산
- **가계부**: 월별 지출 기록
- **관리자**: 회원 관리(목록·검색·강제 탈퇴), 공지 관리, 대시보드

## 트러블슈팅

### 1. INSERT 시 ORA-00001 (PK 중복) 발생 — 유동현

- **문제**: 새 데이터를 등록하면 `ORA-00001: unique constraint violated` 오류가 발생
- **원인**: 테스트용 데이터를 시퀀스를 거치지 않고 PK 값을 직접 넣어 등록했기 때문에, 시퀀스의 다음 값이 이미 존재하는 PK보다 작았음
- **해결**: 테이블의 최대 PK 값을 확인하고 시퀀스를 그 이후 값부터 다시 시작하도록 재동기화
- **배운 점**: 테스트 데이터도 실제와 같은 방식(시퀀스 사용)으로 넣어야 한다는 것

### 2. 다른 PC에서 접속하면 카카오맵만 표시되지 않음 — 유동현

- **문제**: 내 PC에서는 지도가 잘 나오는데, 팀원이 다른 주소(IP)로 접속하면 지도 영역만 빈 화면으로 나옴
- **원인**: 카카오 개발자 사이트에 해당 접속 주소가 웹 플랫폼 도메인으로 등록되어 있지 않았음
- **해결**: 카카오 개발자 사이트에서 사용하는 접속 주소를 도메인으로 추가 등록

## 실행 방법

1. Oracle DB에 테이블 생성
2. `src/main/webapp/WEB-INF/spring/root-context.xml`에서 DB 접속 정보 수정
3. `src/main/resources/mail.properties` 파일 생성 (보안상 저장소에는 올리지 않음)
   ```
   mail.user=발송용_지메일_주소
   mail.password=앱_비밀번호
   ```
4. Eclipse(STS)에서 Tomcat 9로 실행
