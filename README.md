# 짠내맵

착한가격업소를 지도에서 찾고, 절약 챌린지와 커뮤니티로 함께 아껴 쓰는 지역 기반 절약 생활 플랫폼입니다.

## 주요 기능

- **메인 지도**: 카카오맵 위에 착한가격업소 표시, 업종·가격 필터, 지역 검색, 마커 묶음, 북마크
- **회원**: 회원가입, 로그인, 아이디·비밀번호 찾기, 마이페이지
  - 비밀번호 찾기: 아이디와 가입한 이메일을 확인한 뒤, **가입한 이메일(네이버·다음 등 어떤 메일이든)로 인증번호 발송** (3분 제한, 5회 시도 제한)
- **챌린지**: 절약 챌린지 개설·참여, 댓글로 인증
- **커뮤니티**: 자유게시판, Q&A 게시판, 베스트 게시글(추천 수 TOP 10)
- **파티**: 함께 갈 사람 모집, 모임 채팅, 모임비 정산
- **가계부**: 월별 지출 기록
- **관리자**: 회원 관리(목록·검색·강제 탈퇴), 공지 관리, 대시보드

## 트러블슈팅

### 1. 코드 병합 후 한글이 깨지는 문제 — 유동현

- **문제**: 팀원들의 코드를 병합한 뒤, 일부 Java 파일의 한글 메시지와 주석이 `���̵� �Ǵ�`처럼 깨져서 화면에 나오는 안내 문구까지 알아볼 수 없게 됨
- **원인**: 팀원마다 Eclipse의 텍스트 인코딩 설정이 달라, 서로 다른 인코딩으로 저장된 파일이 섞여 있었음
- **해결**: 깨진 파일 10개(회원, 자유게시판, 채팅, 정산 등)의 한글을 복구하고, 프로젝트 인코딩을 UTF-8로 통일
- **배운 점**: 협업을 시작하기 전에 인코딩 같은 개발 환경부터 팀 전체가 맞춰야 한다는 것

### 2. 다른 PC에서 접속하면 카카오맵만 표시되지 않음 — 유동현

- **문제**: 내 PC에서는 지도가 잘 나오는데, 팀원이 다른 주소(IP)로 접속하면 지도 영역만 빈 화면으로 나옴
- **원인**: 카카오 개발자 사이트에 해당 접속 주소가 웹 플랫폼 도메인으로 등록되어 있지 않았음
- **해결**: 카카오 개발자 사이트에서 사용하는 접속 주소를 도메인으로 추가 등록

## 실행 방법

1. Oracle DB에 테이블 생성
2. `src/main/webapp/WEB-INF/spring/root-context.xml`에서 DB 접속 정보 수정
3. `src/main/resources/mail.properties` 파일 생성 (보안상 저장소에는 올리지 않음)
   ```
   mail.user=발송용_지메일_주소
   mail.password=앱_비밀번호
   ```
   - 인증번호를 **보내는 계정**만 Gmail이면 되고, **받는 쪽**은 회원이 가입할 때 적은 이메일이라 어떤 메일이든 상관없음
4. Eclipse(STS)에서 Tomcat 9로 실행
